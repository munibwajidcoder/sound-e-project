1. Project Overview & Problem Statement

SOUND is an integrated web-based entertainment portal developed for SOUND Group to organize and stream Regional (Tamil, Telugu, Hindi, Malayalam, Punjabi, Bengali) and English audio and video entertainment. The platform addresses fragmented media browsing by providing centralized categorization (Artist, Album, Year, Genre, Language), dynamic search, and community review ratings.

2. User / Client-Side Portal (Functional Walkthrough)

🎵 Music & Album Showcase

Users can browse organized song catalogs, studio albums (e.g. Glory, Desi Kalakaar, Coke Studio), and filter instantly by language and genre.

🎬 4K Video Catalog

High-definition video tracks and concert recordings with responsive embed playback, thumbnail posters, and duration tags.

🔍 Instant Search & Quick Filter Pills

Global search bar querying titles, artists, and albums in real time, accompanied by single-click category pills (Qawwali, Hip-Hop, Pop, Romantic).

🎧 In-Browser Audio Modal Player

Non-intrusive floating glassmorphism audio player with animated equalizer bars that streams songs smoothly without interrupting page browsing.

⭐ Reviews & 5-Star Ratings

Registered users can post verified reviews and 1-to-5 star ratings, allowing dynamic average rating calculation per song/video.

✨ Flash "NEW" Badge Indicator

As per client specifications, freshly added music and video tracks automatically display an animated glowing "NEW" badge.

📌 Aptech Specification Compliance (Home Page Layout):
  • Home Showcase: Features Hero branding, live search bar, and curated categories.
  • Latest 5-5 Listing: Home page displays exactly the latest 5 music tracks and latest 5 video tracks dynamically fetched from MySQL database.
  • Responsive 3D Glass Theme: Fully responsive interface optimized for desktop, tablet, and mobile displays without horizontal scrollbars.

3. Administrator Control Portal (Management Side)

The Admin Panel is a dedicated, protected dashboard accessible solely to administrators for complete site management:

📊 Administrative Dashboard

Displays real-time analytics including total music count, total video count, active user count, and recent reviews submitted.

🎶 Music Management (CRUD)

Add new tracks with cover images, audio stream links, duration, artist, album, genre, language, and release year; edit and delete tracks.

📹 Video Management (CRUD)

Create and update video entries with thumbnail covers, streaming URLs (YouTube/MP4), genres, languages, and delete outdated media.

🏷️ Category & User Administration

Create and manage taxonomy categories (Genres, Artists, Albums, Years) and moderate registered user accounts and inappropriate reviews.

4. Relational Database Schema Summary (`sound_db`)

Table Name Primary Key & Foreign Keys Key Fields & Functional Role
users id (PK) name, email, password, phone, address, role ('admin'/'user') — User authentication & profiles.
categories id (PK) name, slug, type ('genre'/'language'/'year') — Taxonomy categorization.
music id (PK) title, artist, album, genre, language, year, audio_url, cover_image, is_new — Song catalog.
videos id (PK) title, artist, album, genre, language, year, video_url, thumbnail, is_new — 4K video catalog.
reviews id (PK), user_id, music_id, video_id (FK) rating (1 to 5), comment, created_at — User feedback and rating calculations.
